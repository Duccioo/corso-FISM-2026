
## Testo

Dentro demo-cli:
    genera un file inventario.txt con l’elenco di tutti i file;
    genera un file soli-md.txt con solo i file .md;
    genera un file conteggio.txt con il numero di righe del README;
    mostra i tre file a terminale.

## Soluzione

cd demo-cli
find . > inventario.txt
find . -name "*.md" > soli-md.txt
wc -l README.md > conteggio.txt

cat inventario.txt
cat soli-md.txt
cat conteggio.txt
cd ..
