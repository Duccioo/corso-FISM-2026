## Testo

Entra in demo-cli.
Crea un branch chiamato feature-docs.
Passa su quel branch.
Crea il file docs/guida.md.
Inserisci due righe nella guida.
Fai un commit.
Torna sul branch principale.
Controlla se il file esiste ancora.
Se vuoi, unisci il branch al principale.



## Soluzione

cd demo-cli
git branch feature-docs
git switch feature-docs

echo "# Guida" > docs/guida.md
echo "Questa guida e' stata creata nel branch feature-docs." >> docs/guida.md
git add docs/guida.md
git commit -m "Aggiunge guida iniziale nella documentazione"

git switch main 2>/dev/null || git switch master
ls docs

git merge feature-docs
ls docs
cd ..
