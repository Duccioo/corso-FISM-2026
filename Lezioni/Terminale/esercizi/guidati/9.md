
## Testo
Entra nella cartella demo-cli.
Inizializza Git.
Aggiungi tutti i file.
Crea il primo commit con messaggio sensato.
Modifica il README aggiungendo una riga.
Verifica lo stato della repository.

## Soluzione

cd demo-cli
git init
git add .
git commit -m "Inizializza struttura del progetto"

echo "Seconda versione del README." >> README.md
git status
git add README.md
git commit -m "Aggiorna il README con una seconda descrizione"
